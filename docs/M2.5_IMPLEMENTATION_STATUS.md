# M2.5 Extension — Implementation Status

## Baseline preserved
The M2.5 extension is developed on the `m2.5-extension` branch. The original `main` branch remains the M1.5 baseline.

## Statistical modules introduced
- `acp_engine.statistics.sem.fit_sem`: SEM estimation through semopy.
- `acp_engine.statistics.longitudinal.fit_longitudinal_mixed_model`: random-intercept mixed model for repeated observations.
- `acp_engine.statistics.panel_regression.fit_panel_models`: pooled OLS, entity-and-time fixed effects, and random effects through linearmodels.

## Important scope limits
These modules are initial implementations and must be exercised against synthetic datasets with known generating parameters. Successful execution is not evidence of causal identification. The longitudinal implementation uses listwise deletion and a random-intercept model. The panel implementation does not yet include a Hausman test. SEM fit indices depend on model identification, estimator, sample size, and distributional assumptions.
