# M3.5 — Qualitative Research Processing and Triangulation Engine

## Branch and baseline
Implementation branch: `m3.5-qualitative-engine`, created from `m2.5-extension`.
The `main` and `m2.5-extension` branches are not modified by this work.

## Implemented in the initial M3.5 increment
- Durable JSONL event log for qualitative research mutations.
- Evidence ingestion with source identifiers, source type, excerpt, and metadata.
- Human-authored code assignments with coder ID, memo, and support/contradict/neutral stance.
- Theme creation and code-to-theme linking.
- Cross-source triangulation summaries with supporting, contradicting, and insufficient-source outcomes.
- Event ID idempotency and conflict detection.
- Thread-safe mutations serialized under a process-local reentrant lock.
- WAL fsync before publishing state, contiguous sequence validation, and restart recovery.
- Tests for validation, idempotency, mixed evidence, recovery, incomplete final WAL record, and concurrent ingestion.

## Methodological limits
The engine does not infer themes or claim to automate Grounded Theory or Phenomenology. Researchers remain responsible for coding decisions, reflexivity, context, saturation, negative-case analysis, and interpretation. The triangulation result is a source-coverage summary, not proof that a proposition is true. Multiple excerpts from one source count as one source.
